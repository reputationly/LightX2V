# Wan2.2 t2v/i2v "模糊/CG感" 调查报告

> 日期:2026-07-11 · 起因:生产 t2v 产物(如瀑布样片)被评"画面糊、像 CG"
> 方法:同 seed 控制变量 A/B × 6 组实验, 六节点并行
> **结论先行:模型无罪(蒸馏/量化/物理全部排除), 真实感的杠杆在"使用侧"——提示词+机位+分辨率+SR。**

## 一、五变量审判结果

| 嫌疑人 | 实验 | 判决 |
|---|---|---|
| **提示词/题材** ⭐ | 同模型:老瀑布(素句)="好假" vs tbest(摄影级描述)="很真实" | **主犯**。素句触发泛化 CG 风;摄影级描述(实拍风格/35mm/自然光/纪录片质感/材质细节)质变 |
| 蒸馏(4步 vs 40步) | t2v_base40(40步 bf16, 50分钟) vs w1d_triton(4步, 234s), 同seed同prompt 720p | **无罪**——"两个效果都好、都没有 CG 感"(且物理倒影双双正确)。4 步白拿 12× |
| 量化(int8) | W1 各组 A/B | 无罪(画质同, 见 W1 报告) |
| 任务类型 | i2v 猫(照片打底)天然真实 vs t2v 从零生成 | **i2v 有先天优势**——真实感敏感场景引导走图生视频 |
| 分辨率 | 480p 版实验被评"太模糊" | 从犯——真实感评估/交付至少 720p |
| 运镜(静 vs 动) | tcam720 A/B(720p, 同seed同提示词, 唯一变量固定机位vs前推) | **无罪**——"两个都还可以"。此前"运镜显糊"实为 480p 分辨率背锅 |
| SR 后处理 | srfix_waterfall("确实强一些但不根治")/tbest_1080p("很真实") | **有效增强剂**:对好底子锦上添花;救不了烂提示词的底子 |

## 二、真实感处方(产品落地)

```
① 提示词增强(主杠杆, 零成本):
   素句 → 摄影级模板(实拍风格/镜头参数/光线/材质细节/纪录片质感)
   落点: 画布助手自动改写 / new-api 提示词增强开关(use_prompt_enhancer 或网关模板)
② 真实感敏感场景引导 i2v(照片打底)
③ 交付分辨率 ≥720p
④ 链路末尾挂 SeedVR2 3B(canvas §5.8 既定架构, 兼职"真实细节增强器")
⑤ 运镜不设限(720p 下动静皆真, tcam720 已终审)
```

**样片证据链**(NFS outputs/):`cmp_seko_waterfall_720p49.mp4`(起点,差) → `tbest_720p.mp4`(处方①②③,很真实) → `tbest_1080p.mp4`(+④,很真实)。同一套生产权重。
